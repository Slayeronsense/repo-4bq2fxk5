## 北师大 · 四下「认识方程」学完（典型边界）

依据：`4下/五_认识方程/*.yaml`、`4下/三_小数乘法/02_小数点搬家.yaml`

### 可用

- 找等量关系；**设一个未知数**；列**一个**方程
- 用等式性质解一步、两步方程（**系数为整数**，如 `6x+9x=30`）
- 求出一个量后，用**题目等量关系 + 整数乘除**求另一个量（不再设第二个字母）
- 倒推/开火车（猜数游戏课延伸）
- 小数：**意义、加减、乘**（四下第三单元）；可用元角分转化，但勿默认学生会小数除

### 禁用（知识树明确后移或未教）

| 禁用项 | 依据 |
|--------|------|
| **二元方程 / 设 x、y 两个未知数** | 四下只教一个未知数的方程；无「方程组」 |
| **两个方程联立** | 同上 |
| **用一个小数系数表示另一量**（如 `y=1.5x`、`3÷2`） | 等价于小数除法，四下未学 |
| **小数除法**（含 `0.3÷2`、除以小数） | `4下/三_小数乘法/02_小数点搬家` → `later`，**when_taught: 5上** |
| 分数乘除、复杂五上方程应用 | `later` / 五上 |

### 两价应用题（如钢笔+圆珠笔）标准讲法

1. **只设一个未知数**（如圆珠笔 `x`）。
2. 用等量关系把另一量写成 **整数倍的 x**（如 4 支钢笔 = `6x`，由「2 钢笔=3 圆珠笔」两边×2，**不要写 1.5x**）。
3. 列一个方程：`6x+9x=30`。
4. 求出 `x` 后，用原句关系 + **整数除法** 求另一单价（如 `6÷2=3`）。

### 常见错位（讲题时必须改写）

| 小太阳/人教里常见 | 北师大四下边界 | 处理 |
|------------------|---------------|------|
| 列 `x、y`、联立 | 未教二元 | 一个未知数 + `6x` 类整数倍换元 |
| `1.5x`、`3÷2` | 小数除在**五上** | 用 `3x`、`6x` + 整数除法 |
