# 04 · 预习向语料说明（归档用 · 非独立工作流）

> **2026-06-10 定稿**：小太阳口播「预习」的视频，**讲题逻辑与正课完全相同**——也是先复习前面、再引新知，走 SKILL 主流程 Step 0→0.5→1–4。  
> 本文件**不定义单独预习模式**；仅说明语料分类与蒸馏时的注意事项。

## 与正课的关系

| | 正课逐字稿 | 预习向逐字稿 |
|--|-----------|-------------|
| 讲题主流程 | Step 0→0.5→1–4 | **相同** |
| registry 检索 | Step 0.5 同等对待 | **相同** |
| 学情边界 | Step 0 必读 | **相同**（预习常涉下一册内容，更须查 `later`） |
| manifest 标签 | keep-{册} | 可标 `preview`（仅索引，不改工作流） |

## 蒸馏时注意

- 预习向视频常讲**下一册或超当前 boundary 的工具** → 安全等级多为黄/红，必须写 `adapted_script` 适配版。
- 口播「预习」≠ Skill 里另开一步；蒸馏产出仍进 `ingest-registry`，讲题时 Step 0.5 正常检索。
