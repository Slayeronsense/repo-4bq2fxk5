## 三、跨年级迁移分析表

| 方法/题型 | 三四年级版 | 五年级版 | 六年级可迁移点 |
|---|---|---|---|
| **分段计费** | 无（生活初步感知） | 分两段；出租车模型；正向求费用 | 分三段+；费率用百分数；逆向求数量 |
| **植树/间隔** | "间隔比树少1"；简单整除 | 站-间隔转化；间隔与时间对应 | 速度比进入间隔模型；间隔数→正比例 |
| **拉窗帘/等积变形** | 无 | 三角形顶点在平行线上滑动→面积不变 | 梯形上底平移→面积不变；连续两次变换 |
| **用字母表示数** | 用□或?表示未知数 | 用x表示；200-2x型表达式 | 字母系数为分数/百分数；y=kx型 |
| **不变量** | 同时加减→差不变 | 总量不变；整数/小数倍份数 | 分数倍份数模型；策略选择更复杂 |
| **列方程** | 无 | 设x→找等量关系→解方程 | 方程含分数运算；分配律展开 |
| **面积转化** | 简单组合图形 | 平行四边形→长方形（沿高剪拼） | 圆→近似长方形；圆柱→近似长方体 |
| **画图分析法** | 简单线段图 | 画对齐线段图；分段画区间 | 线段图承载分数/百分数；数轴承载三段+费率 |

## 四、易错点汇总

| 题型/知识点 | 易错描述 | 小太阳的应对 |
|---|---|---|
| 分段计费（三段） | 把区间上界当作区间宽度 | 画数轴区间图，标出每段起止点和宽度 |
| 分段计费变式 | 逆向题中不考虑"不足按整段计算" | 画完整分段展开图验证边界 |
| 植树/爬楼 | "第N层"直接当间隔数 | 强调间隔数=层数-1 |
| 植树比赛 | 认为"差1层就永远差1层" | 必须转化为间隔比 |
| 不变量问题 | 分不清"拿之前"和"拿之后"的倍数关系 | 线段图上明确标注"拿之后" |
| 不变量问题 | 小数倍的份数除法出错 | 从整数份过渡到小数份 |
| 列方程 | 混淆"变化前"和"变化后" | 所有量统一到同一时刻 |
| 用字母表示数 | 代入求值时把单位也代进去 | "代入的时候不用带单位" |
| 拉窗帘模型 | 只凭视觉判断面积不变 | 先找平行线→确认底高不变→结论 |
| 面积推导 | 底和高不对应 | 「底和高一定是一一对应」 |

## 五、高价值证据（5条）

1) `五上第一单元-分段计费`——「不要一来就写算式，把这边分析清楚了」

2) `五上-分段计费变式`——「问法变了它仍然是分段计费问题……方法没理由变」

3) `拉窗帘模型的应用`——「上底的位置变了……面积没有变……这就是拉窗帘模型的应用」

4) `五上-列方程解决倍数问题`——「用列方程来解的话，还用得着去想总数不变吗？不用」「感受到了吗？」

5) `五上-抓住不变量解决问题`——「1.4倍，我们就可以把它叫做1.4份」

## 六、特别发现

### 1. 标题与内容不符
`五上-列方程解决行程问题` 实际内容是平行四边形面积公式推导（沿高剪拼），非行程问题。

### 2. 六年级"专属新方法"稀缺
12条素材中没有百分数应用题、比和比例、圆面积、圆柱圆锥等六年级核心单元的直接讲解。

### 3. 最有价值的迁移发现
- **速度比自发涌现**：学生在爬楼梯问题中自发使用"速度是1.5倍"——六年级"比和比例"的萌芽
- **分三段报销**：最接近六年级独有内容的素材
- **梯形上底平移**：将五年级"拉窗帘"升级为更复杂的应用
