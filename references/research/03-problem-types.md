# 03 · 题型→方法路由（T01–T31 + G5 + G6）

输入题目后先匹配题型，再查下表。**年级边界见 `05-grade-boundaries.md`**。

## 北师大适用说明

- **题型路由不分册存储**：本表 56 个题型为全册通用索引，不按 1上–6下 拆文件。
- **讲题时先 Step 0 定当前册**（见 `05-grade-boundaries.md`），再查本表匹配题型与方法。
- **表中「北师大适用册」**为典型启用册（可多册并列）；非唯一限制，低册题可上移到高册复现。
- **「禁用提示」须与当前学情 `later` 交叉验证**：表内禁用为通用提醒，最终以 boundary YAML 的 `known` / `later` 为准。

### 已有题型新证据补充（来源：shard-A + shard-B）

## ======= 3下–4下 扩展题型（T14–T31）=======

### T14 统筹优化（烙饼/沏茶/路线规划）
- **识别特征**：涉及多件事可同时进行、求最短时间/最优方案
- **优先方法**：烙饼优化法（M34-02）、沏茶统筹法（M34-04）、画路线图
- **北师大适用册**：4上
- **证据（shard-A）**：`四上第八单元：烙饼问题`、`四上八单元：烙饼问题（同时烙4张）`、`四上第八单元：沏茶问题`

### T15 博弈策略（轮流报数/扑克牌）
- **识别特征**：两人轮流操作、每次有限选择、求必胜策略
- **优先方法**：轮流报数·掌控策略（M34-03）
- **北师大适用册**：4上
- **证据（shard-A）**：`四上第八单元：轮流报数游戏`
- **证据（shard-B）**：`四上期末复习：扑克牌游戏，保证胜利`——固定一轮总取数→总数÷一轮数的余数→先手取余数

### T16 得分问题（鸡兔同笼变体）
- **识别特征**：答对得X分、答错扣Y分（或不做得0分），已知总题数和总分求对错数
- **优先方法**：假设法/损失法→差额÷（做对得分+做错扣分）；或列表法
- **北师大适用册**：4下
- **证据（shard-A）**：`四年级寒假预习15_得分问题`——"做错一道题损失的是5+2=7分"
- **证据（shard-B）**：`四下：得分问题`、`四下-鸡兔同笼问题变式3`——"把一道错的看成一道对的，一共多了十二分"

### T17 翻折/对称类几何
- **识别特征**：折叠纸张、已知折后图形求原图或求长度/角度
- **优先方法**：翻折对称法（M34-05）
- **北师大适用册**：4上
- **证据（shard-A）**：`四上第五单元：长方形折叠成梯形`、`四上第五单元思维拓展：等腰梯形与翻折`
- **证据（shard-B）**：`四上期末复习：翻折问题`、`四上思维拓展：翻折问题（难）`——"翻折部分和原来完全一样"

### T18 工程问题（归一型）
- **识别特征**：甲单独完成需A天，乙单独完成需B天，合作需多少天
- **优先方法**：工作量归一法（画线段图分配）
- **北师大适用册**：3下/4上
- **证据（shard-A）**：`思维题：一箱苹果`——"60天一共吃了五箱，吃一箱需要60÷5=12天"

### T19 小数认识/性质/比较/小数点移动
- **识别特征**：小数的意义、性质（末尾加减0）、大小比较、小数点移动引起大小变化
- **优先方法**：数位顺序表法、分数桥梁法（M34-06）、位值比较法
- **北师大适用册**：4下
- **证据（shard-A）**：`四年级寒假预习10/11/12/13`

### T20 运算律/综合算式
- **识别特征**：判断使用了什么运算律、分步改综合、综合改分步
- **优先方法**：标顺序法、等量代换法（M34-17）
- **北师大适用册**：4上/4下
- **证据（shard-A）**：`四年级寒假预习2`、`复习写综合算式`、`改写成综合算式`

### T21 初商与正确商/试商调商
- **识别特征**：已知初商和调整方向，求除数或被除数中的未知数
- **优先方法**：此消彼长法（M34-01）+ 逐一代入验证
- **北师大适用册**：4上
- **证据（shard-A）**：`四上第六单元：思维拓展（初商与正确商）`两个文件

### T22 除法竖式谜
- **识别特征**：除法竖式中有空格，需要推理填数
- **优先方法**：从"被分走的"入手推理；找突破口法（M34-12）
- **北师大适用册**：4上
- **证据（shard-A）**：`四上第六单元：除法竖式谜`两个文件

### T23 买赠问题
- **识别特征**：买X送Y，已知总需求量或总金额，求实际花费或实际数量
- **优先方法**：①打包法（买+送=一组）②先不看活动再看活动
- **北师大适用册**：4上
- **证据（shard-B）**：`四上期末复习：买赠问题（买五送二）`

### T24 平均数变式
- **识别特征**：已知改变前后的平均数和改变的某个数，求原来/现在的值
- **优先方法**：分别求改变前后的总数→对比差值→差值归因于改变的那个数
- **北师大适用册**：4下
- **证据（shard-B）**：`四下：平均数变式。`

### T25 钟表角度问题
- **识别特征**：求某时某分时针和分针的夹角
- **优先方法**：①一大格=30° ②精确定位时针 ③算两针角度差
- **北师大适用册**：4上
- **证据（shard-B）**：`四上期末复习：易错题（时间与角的大小的关系）`

### T26 植树/间隔问题变式
- **识别特征**：爬楼梯比赛、层数与间隔数的转换；信号灯变换次数（间隔数+1）
- **优先方法**：层数→间隔数（-1），按速度比计算对方间隔数，间隔数→层数（+1）
- **北师大适用册**：5上（G5-T18）；**北师大4上无植树/间隔正式课**，勿主挂4上
- **证据（shard-B）**：`植树问题易错题`
- **证据（抖音）**：`7397232853357989147`——信号灯每30秒变换，40个间隔→41次（+1）

### T27 桶和油/容器问题
- **识别特征**：连桶/连瓶共重X千克，用去一半后连桶共重Y千克
- **优先方法**：画线段图（原来vs现在），差值=用去的一半→×2=全部油→总-油=桶
- **北师大适用册**：4下
- **证据（shard-B）**：`四下六单元-桶和油的问题`——"边读题边画图，一下就呈现出来了"

### T28 杯子叠放/堆叠问题
- **识别特征**：杯子/碗叠放，总高度=底层一个的高度+上面若干个的露出高度
- **优先方法**：对比两种叠法求单个露出高度→代入求底层高度→(总高-底层)÷露出高度+1=总数
- **北师大适用册**：4下
- **证据（shard-B）**：`四下期末复习-杯子叠起来的高度`

### T29 多边形内角和
- **识别特征**：求多边形内角和，拆分三角形
- **优先方法**：拆分三角形法（M34-13）→从一个顶点连线→拆分为(n-2)个三角形→180°×(n-2)
- **北师大适用册**：4下
- **证据（shard-B）**：`四下第五单元：求多边形的内角和`
- **注意**：从内部一点拆分会多算一个周角360°

### T30 等底等高面积/蝴蝶模型
- **识别特征**：梯形中找等底等高的三角形，已知部分面积求整体
- **优先方法**：①找等分线段→等底等高三角形面积相等 ②蝴蝶模型
- **北师大适用册**：5上
- **证据（shard-B）**：`图形拓展题：等底等高的三角形面积相等`
- **学情风险**："蝴蝶模型"是竞赛术语，课标内仅要求理解等底等高面积相等

### T31 小数计数单位转换
- **识别特征**："X有多少个0.01"等计数单位转换题
- **优先方法**：统一计数单位法（M34-16）→末尾补零对齐→去掉小数点直接读数
- **北师大适用册**：4下
- **证据（shard-B）**：`小数的计数单位（易错题）`——"4.9有49个0.1，不是9个"
